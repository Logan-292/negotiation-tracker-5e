# Negotiation Tracker
Трекер переговоров (Интерес / Терпение / Мотивации / Подводные камни)
Установка: распаковать папку в `Data/modules/`, включить в мире с системой dnd5e. Кнопка «Переговоры» — в панели инструментов токенов (только ГМ),
или в макросе: `game.modules.get("negotiation-tracker-5e").api.open()`.
Пороги успеха (по умолчанию 10 / 15) меняются в настройках модуля. В окне можно вести несколько параллельных разговоров, в каждом — несколько НПС с отдельными шкалами и мотивациями.

## Установка через Foundry
https://github.com/Logan-292/negotiation-tracker-5e/releases/latest/download/module.json

Поддержка систем: D&D 5e, Pathfinder 2e, WFRP 4e, Call of Cthulhu 7e / Pulp Cthulhu, Vampire 5e, OSR (OSE), Draw Steel. Выбирается автоматически или вручную в настройках.
Три оформления: фэнтези (свиток), киберпанк (терминал), офис (документ). Переключаются кнопками в окне трекера.
Несколько NPC в одном разговоре: один бросок бьёт по всем отмеченным NPC, каждый обрабатывается по своим мотивациям и ловушкам, со своими DC.
Параллельные разговоры: вкладки, у каждого свои NPC и журнал.
Игроки бросают сами: запрос уходит в чат, результат автоматически попадает в трекер.
Под каждую систему свои броски: пулы d10 и кубы Голода (Vampire), уровни успеха (WFRP, Cthulhu), бонусные и штрафные кубы (Cthulhu), edge/bane (Draw Steel), реакция 2d6 (OSR).
Названия мотивов скрыты в чате, игроки видят только реакцию NPC.
