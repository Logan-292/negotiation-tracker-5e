# Negotiation Tracker

Трекер переговоров для Foundry VTT: Интерес, Терпение, Мотивации и Подводные камни. Основан на правилах Draw Steel (MCDM Productions); модуль неофициальный и не связан с MCDM.

## Возможности
- Несколько параллельных разговоров, в каждом несколько НПС со своими шкалами, мотивациями и Сл.
- Один аргумент действует сразу на нескольких НПС, у каждого результат считается отдельно.
- Проверку запрашивают у игроков через чат: они бросают сами, результат попадает в трекер.
- Три оформления: фэнтези (свиток), киберпанк (терминал), офис (документ).

## Поддерживаемые системы
| Система | Id в Foundry | Как бросается |
|---|---|---|
| D&D 5e | `dnd5e` | штатный бросок навыка системы |
| Pathfinder 2e | `pf2e` | d20 + бонус, степени успеха |
| Warhammer Fantasy 4e | `wfrp4e` | d100 против значения, уровни успеха (SL) |
| Call of Cthulhu 7e / Pulp Cthulhu | `CoC7` | d100 ≤ навыка, уровни успеха, бонусные и штрафные кубы |
| Vampire: The Masquerade 5e | `vtm5e`, `wod5e` | пул d10, кубы Голода, успехи |
| OSR (Old School Essentials) | `ose` | 2d6 реакция или d20 «не больше значения» |
| Draw Steel | `draw-steel` | 2d10 + характеристика, edge/bane |
| Другие | — | универсальный d20 |

Для всех систем, кроме D&D 5e, бросок делается средствами самого Foundry: игрок вводит нужное число с листа (бонус, значение навыка), результат попадает в чат обычным броском. Данные листа персонажа модуль не читает, таланты и эффекты системы в такие броски не подключаются.

Pulp Cthulhu использует те же броски, что и обычный Call of Cthulhu 7e, отдельного режима не требует.

Систему можно выбрать вручную: Настройки модуля → «Система правил».

## Установка
`Setup → Add-on Modules → Install Module → Manifest URL`:
`https://github.com/Logan-292/negotiation-tracker-5e/releases/latest/download/module.json`

Открыть трекер: кнопка «Переговоры» в панели токенов (только ведущий) или макрос
`game.modules.get("negotiation-tracker-5e").api.open()`.

Как выпускать обновления: см. `RELEASING.md`.
